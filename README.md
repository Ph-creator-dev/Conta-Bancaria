# Conta Bancária
Um sistema de conta bancária feito em python utilizando os conceitos de POO.

# Conceitos de POO utilizados
- Polimorfismo
- Encapsulamento
- Herança

# Funcionalidades
- Realizar saques
- Realizar depósitos
- Realizar transferências
- Ver rendimento

# Extras
- Proibição da alteração direta do saldo
- Validação do método sacar
- Validação do método depositar

# Utilização
Dentro do arquivo main.py, importe as classes usadas no arquivo Conta_Bancária.py, crie objetos com id, nome e saldo. Use os métodos sacar para tirar dinheiro, depositar para colocar dinheiro, transferir para passar dinheiro para outras contas, e ver_rendimento para ver quanto o seu banco renderá uma quantia de dinheiro baseado na quantidade de dias utilizando juros compostos

# Aviso
Os nomes utilizados no projeto são somente para ilustração, as classes utilizadas não tem nenhuma relação com os bancos da vida real a não ser o nome.
